# prometeus-catalog

Data file endpoint for the Prometeus Android TV updater.

- [`catalog.json`](catalog.json) — opaque signed update payload (AES-256-GCM,
  envelope `PENC1.<iv>.<ct>`). Generated by the release pipeline; it is NOT
  plain JSON by design.
- The client downloads it every 6 hours (or on demand via "Actualizar
  catálogo"), verifies and applies it incrementally. Older app builds that
  only understand plain JSON simply keep their current state.
- No source code, credentials or personal data live in this repository.

> Nota de mantenimiento: el payload es un manifiesto de actualización cifrado
> del actualizador de Prometeus. Para regenerarlo se usa el pipeline de
> release (ver repo principal, privado). Regla del formato: `v` crece con
> cada publicación; los clientes aplican cuando `v` > última aplicada y
> nunca degradan contenido existente.
