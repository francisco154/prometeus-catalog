## Qué significa cada campo del catálogo (referencia rápida)

```json
{ "i": "special-ops-lioness", "t": "Special Ops: Lioness", "k": "serie",
  "tt": "tt13111078", "em": 1,
  "p": "<póster vertical metahub>", "b": "<backdrop metahub>",
  "h": "<coverHorizontalUrl de la plataforma — Hero 16:9>",
  "e": [ { "n": 1, "q": 8, "x": ["<título ep 1>", "…"],
         "w": [ {"w": "<websiteParam doblaje>", "v": "doblaje", "y": "flixlat"},
                {"w": "<websiteParam sub>",      "v": "sub",      "y": "flixlat"},
                {"w": "<websiteParam base>",     "v": "base",     "y": "flixlat"} ] } ] }
```

- La app arma la URL de detalle `/{lang}/detail/drama/{w}/{ep}` con el
  frente `y` y resuelve en runtime: lista de episodios con foto,
  calidades y m3u8 firmado (token de sesión).
- La primera fuente de `w[]` es la principal (la app la prefiere).
- Los m3u8 firmados rotan: por eso el catálogo guarda `websiteParam`
  y no el link directo al stream.
